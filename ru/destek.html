Частые вопросы

Времена намазов показаны неверно

Времена рассчитываются по выбранному местоположению и методу расчёта. Проверь по порядку:

  1. Местоположение: вкладка «Я» › Местоположение. Нажми «Определить моё местоположение» или выбери свой город из списка. Если выбран другой город, времена будут по нему.
  2. Метод расчёта: вкладка «Я» › Метод расчёта. Для Турции выбери «Управление по делам религии Турции (Диянет)»; вариант «Автоматически по городу» подбирает метод твоей страны.
  3. Время аср: на том же экране проверь выбор между «Аср аль-авваль» и «Аср ас-сани»; разница между ними может быть около часа.
  4. Дата по хиджре: если календарь хиджры сдвинут на день, в разделе Инструменты › Календарь хиджры можно задать поправку ±2 дня.

Разница в несколько минут с официальным календарём может быть из-за запаса осторожности — это нормально.

Не приходят уведомления
  1. На iPhone открой Настройки › Уведомления › Nur; переключатель «Допуск уведомлений» должен быть включён.
  2. Если включён режим «Фокусирование» («Не беспокоить», «Сон»), добавь Nur в разрешённые приложения.
  3. В приложении должно быть включено вкладка «Я» › Уведомление об азане. Напоминания о сухуре, тахаджуде и джума — в разделе Инструменты › Напоминания.
  4. При смене местоположения уведомления сами перестраиваются под новые времена.
  5. iOS ограничивает число уведомлений, которые приложение может запланировать заранее; Nur планирует примерно на неделю вперёд. Открывай приложение хотя бы раз в неделю, и уведомления будут приходить без перерывов.
Направление киблы отклоняется
  1. Откалибруй компас: несколько раз опиши телефоном в воздухе восьмёрку.
  2. Отойди от магнитных чехлов, динамиков, металлических столов и электроники — они сбивают компас.
  3. Включи Настройки › Конфиденциальность и безопасность › Службы геолокации › Системные службы › Калибровка компаса.
  4. Убедись, что местоположение верное: угол киблы рассчитывается по выбранному местоположению.
Аудио Корана не воспроизводится или не загружается
  1. Аудио аятов приходит из интернета. Проверь Wi-Fi или сотовую связь; в Настройки › Сотовая связь у Nur должен быть разрешён мобильный интернет.
  2. Если загрузка прервалась, попробуй ещё раз: недокачанные файлы удаляются, и загрузка выполняется заново.
  3. Загруженные суры воспроизводятся без сети. Увидеть и удалить загруженное можно в разделе Читать Коран › Настройки чтения.
  4. Кнопка прослушивания есть только у дуа из аятов Корана; у остальных дуа она не показывается.
